# 评测数据说明

## 这批数据是真的吗

`dataset.json` 不是从生产项目或公开漏洞数据库直接复制来的真实代码集，而是我为了学习和回归测试手工编写的 30 个最小 Python 样例。这样做的优点是每条样例都短、意图明确、行号容易复核，也不会把任何真实项目代码或密钥带进仓库；缺点是它不能代表真实项目的复杂度。

因此报告中的 `1.0000` 只能这样解释：当前本地规则在这 30 条固定标注上的 Precision、Recall、F1、算法识别率和行号命中率都与标注一致。它不是“密码审查已经达到生产级”的证明。

本次扩展没有覆盖或改写原有 `dataset.json`，而是新增 `targeted_v2.json`。它包含 18 条面向消息通信和密钥管理的最小样例，覆盖 RC4、MD4、弱 HMAC、固定 nonce/IV、短 RSA、弱 PBKDF2、日志泄露、CRC32、密钥流向和敏感值比较，并配有安全反例。两份数据集分别回答“旧能力是否保持”和“新增能力是否有效”，不能把两者的分数混成一个生产指标。

## 标签放在哪里

每个样例都包含以下字段：

- `source`：待审查的 Python 代码片段；
- `expected_rules`：预期触发的本地规则 ID；
- `expected_algorithms`：预期盘点出的算法名称；
- `expected_lines`：规则对应的预期行号；
- `secret_literals`：仅用于检查报告、JSON 和 checkpoint 是否发生敏感信息泄漏；
- `expect_unknown`：标记仅凭当前局部源码无法确定、应该交给 Agent 或人工复核的场景。

这些字段就是评测的参考答案，放在公开的 JSON 数据集中。`evals/runner.py` 重新运行本地工具，逐条比较“实际输出”和“参考答案”，不会读取预先保存的结果来凑分。

## 30 条样例覆盖什么

| 范围 | 样例 | 目的 |
| --- | --- | --- |
| 01-08 | DES、3DES、ECB、MD5、随机数、硬编码凭证和组合问题 | 检查已知风险能否被规则捕获 |
| 09-12 | AES-GCM、SM4、RSA、SHA-256 | 检查安全或可接受算法不会被误报 |
| 13-14、29 | 注释和普通字符串 | 检查 AST 解析不会把文本内容当成执行代码 |
| 15-19、24-25 | 别名、函数封装、多 Finding | 检查简单语法变化和多问题输出 |
| 20-21、30 | 参数传递、自定义 nonce、运行模式来自调用者 | 检查“不知道”边界，而不是强行下结论 |
| 22-23、26-28 | 口令、令牌、ChaCha20、SM3、RSA 安全用法 | 补充凭证和国密/现代算法覆盖 |

## 扩展样例覆盖什么

`targeted_v2.json` 专门验证新增的语义规则：

- 过时算法和弱摘要：RC4、MD4、HMAC-MD5；
- 参数与生命周期：固定/复用 nonce、固定 IV、RSA 512 位密钥、PBKDF2 低迭代和弱摘要；
- 凭证与数据流：硬编码共享密钥、密钥进入 token、密钥或明文进入日志；
- 完整性与比较：CRC32 冒充完整性校验、敏感值使用 `==`；
- 安全反例：环境变量密钥、`secrets.token_bytes` nonce、`hmac.compare_digest`。

## 怎么运行

```powershell
python cli.py eval --dataset evals/dataset.json
python cli.py eval --dataset evals/targeted_v2.json
python cli.py eval --mode agent --dataset evals/dataset.json
```

默认是 `baseline`，只衡量确定性本地规则。`--mode agent` 使用当前 Provider 跑同一批输入；没有 API Key 时仍是离线 Provider，不能当作真实 GPT 评测。真实 GPT 的结果会受模型版本、Prompt、网络和成本影响，应单独保存运行记录，不与离线基线混在一起。

## 如何理解“测试通过”

`pytest` 的 52 个测试主要验证代码契约，例如工具白名单、证据门槛、补丁指纹、敏感信息脱敏、checkpoint 恢复、扩展规则的安全反例和 UI 入口。测试通过表示这些预先写下的工程约束没有被破坏；它和评测集的质量指标是两件事。

真正有说服力的后续工作，是在取得授权后加入真实项目片段，保留样例来源、脱敏记录和人工复核标签，并把它作为独立的外部验证集，而不是继续扩大一批完全由规则作者自己写出的代码。
